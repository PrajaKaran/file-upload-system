# File Upload System API

A modern, secure, and fully-featured File Upload System built with Node.js, Express, and Multer.

## Features
- **Modern UI:** Premium Glassmorphism frontend design with drag-and-drop support and micro-animations.
- **Secure Backend:** Configured with strict file type validation (only accepts JPEG, PNG, GIF, and PDF).
- **Size Limits:** Enforces a strict 5MB file upload limit to prevent abuse.
- **Unique File Naming:** Automatically generates collision-free file names using timestamps.

## Setup Instructions

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start the Development Server:**
   ```bash
   npm run dev
   ```

3. **Access the App:**
   Open your browser and navigate to `http://localhost:3000`.

## Tech Stack
- **Backend:** Node.js, Express.js
- **File Parsing:** Multer
- **Frontend:** Vanilla HTML, CSS (Glassmorphism), JavaScript
